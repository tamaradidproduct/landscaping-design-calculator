# Top bar — decisions

Date: 2026-10-24 · Spec: `docs/superpowers/specs/2026-10-24-top-bar-design.md` · Plan: `docs/superpowers/plans/2026-10-24-top-bar.md`

## Decided
- A 48 px top bar across the editor replaces the canvas plan-header pill, the canvas Undo/Redo bar and the panel's Edit | Sheet toggle.
- Left: ← Plans, plan name, ⋯ menu (Rename, Archive, Delete). Centre: Edit | Preview. Right: Undo, Redo, hairline, Export.
- Export is a placeholder: an enabled button that shows "Export is coming soon".
- Preview (was Sheet) is read-only: hides the plot plan for display only, fits the drawn plan, switches the drawing tools, ⌘Z and the bar's Undo/Redo off. Edit restores plan visibility, zoom and pan.
- Zoom and Fit stay at the canvas's bottom-right.

## Built as
- `top-bar.ts` renders the bar once; `PlanHead` keeps the left cluster (its root is `#top-bar-left`). Undo/Redo and the switch are patched in place, not re-rendered, so the open menu is not destroyed.
- `plan-bounds.ts` (what Preview fits) and `fitRect` in `view.ts`; `fitRect` returns null for a zero-size rectangle and the caller falls back to Fit page.
- In Preview the tool is silenced in `main.ts` (pointer taps, hover, a capture-phase key listener), with no change to the drawing tool.

## Left over
- The `--width-plan-head` token is now unused; it comes from the design-system artifact, so it is removed there first, then synced.
- Export flow itself; whether Export opens a menu.
