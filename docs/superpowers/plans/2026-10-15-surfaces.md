# Surfaces (stage 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Contractors add material zones (hardscape + softscape) to the lot: pick a material, draw, see it solid on the plan, and resize it by typing an edge length.

**Architecture:** A surface is a new `OutlineKind` (`'surface'`) with a `material`, so the existing outline tool (drawing, snapping, curves, Square, undo, cards, cutting) carries over. Pure helpers decide section and cutting order; a new `stretch.ts` does the typed-length resize; a new `surfaces-ui.ts` renders the Surfaces section; patterns are SVG `<pattern>`s defined once in the document.

**Tech Stack:** Vite + TypeScript (no framework), vitest, polygon-clipping 0.15.7, Playwright (`playwright-core`, Chrome) against the dev server on :5180.

**Spec:** `docs/superpowers/specs/2026-10-15-surfaces-design.md`

## Global Constraints
- All commands run in `plan-builder/`. Done = `npm run lint`, `npm run typecheck`, `npm test` pass, plus the Riesberg Playwright checks (`node scripts/check-<name>.mjs ../samples/riesberg-plot-plan.pdf`; dev server via preview_start `plan-builder`; `check-step1` needs `plan-builder-preview` on :5181).
- Tokens live in `design-system/tokens.json`; run `npm run tokens` to regenerate `src/styles/tokens.css` (never edit it by hand). Every `var(--x)` in `base|components|plan.css` must be a token (`tokens.test.ts`); the only exception is the per-shape `--c`.
- Controls ≥ 44 px; copy in plain contractor language; no new dependencies.
- Surfaces never create scale references; the scale only comes from outline edges.
- Do not push or open a PR until the user says so. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
- **A zone drawn partly or wholly outside the lot**: clipped to the lot; wholly outside → nothing shown on the plan but its row still selects it and nothing throws (test in Task 2).
- **Resizing on a stretched plan** (non-identity correction): the typed length is the true length (test in Task 3).
- **Redrawing the plot boundary while zones exist**: zones stay; "Add surface…" is hidden until the boundary closes again; Cancel restores it (check in Task 7).
- **Typing a length on a zone edge before any scale**: no field, only "Set the scale on an outline edge first"; `refs` unchanged (check in Task 7).
- **Undo after a material change or a resize**: each is exactly one undo step (check in Task 7).

### Task 3: Stretch a zone to a typed edge length

**Files:**
- Create: `src/stretch.ts`, `src/stretch.test.ts`

**Interfaces:**
- Consumes: `Correction`, `applyCorrection`, `invertCorrection` (`scale.ts`); `edgePoints`, `edgeMid`, `bulgeToward` (`outline.ts`); `Tidied` (`square.ts`).
- Produces: `stretchEdge(pts: Point[], bulges: number[] | undefined, i: number, fixed: 0 | 1, length: number, m: Correction): Tidied` — `length` in true-shape points (caller passes `feet / cal.ftPerPt`); `fixed` 0 = corner `i` stays, 1 = corner `i+1` stays. Also `trueEdgeLength(pts, bulges, i, m): number`.

- [ ] **Step 1: Write failing tests** in `src/stretch.test.ts`:
  - rectangle 12×20 (pts in points, identity): stretch edge 0 (length 12) to 16 with `fixed 0` → corners `(0,0),(16,0),(16,20),(0,20)`; with `fixed 1` → `(−4,0),(12,0),(12,20),(−4,20)`.
  - result keeps all four angles 90° (`cornerAngle` = 90 ± 1e-9).
  - correction `{a:1,b:0,c:0,d:1.1}`: stretching a vertical edge to true length 22 gives `trueEdgeLength` 22 (± 1e-9), and the page-space result differs from the identity case.
  - curved edge (bulge 3 on a 12-long chord) stretched to arc length 20 → `trueEdgeLength` 20 (± 1e-6); every other bent edge still passes through its stretched midpoint.
  - a slanted edge on a freehand shape: the fixed corner doesn't move; corners on the fixed side of the perpendicular through it move back, the others forward (sign of `(P−F)·u` preserved).
- [ ] **Step 2:** `npx vitest run src/stretch.test.ts` → FAIL.
- [ ] **Step 3:** Implement. Algorithm (not determined by the signature):
  ```
  T = applyCorrection(m, ·), B = applyCorrection(invertCorrection(m), ·)
  work in true space: q = pts.map(T); F = q[fixed ? i+1 : i]; u = unit(q[i+1] − q[i])
  move(k)(P) = P + (k − 1)·((P − F)·u)·u
  mids = edges' midpoints via edgeMid (page) → T
  straight edge i: k = length / |q[i+1] − q[i]|
  curved edge i: bisection on k ∈ [1e-3, 1e3] until |trueEdgeLength(k) − length| < 1e-9·length (monotonic in k)
  result pts = q.map(move(k)).map(B); bulge j = bulgeToward(a'_j, b'_j, B(move(k)(mid_j)))  (0 stays 0)
  ```
- [ ] **Step 4:** `npx vitest run src/stretch.test.ts` → PASS.
- [ ] **Step 5:** Commit `feat(plan-builder): stretch a shape to a typed edge length`.
