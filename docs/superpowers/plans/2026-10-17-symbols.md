# Plant and Object Symbols Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Place 51 plants and 14 objects from the Figma symbol library on the plan at true size (move, rotate, delete, hide), with a live plant list in the app.

**Architecture:** A bundled library (art, photo, thumbnail, researched size per symbol) built by a script from Figma. Placed symbols are plain data (`symbols` in the plan), held and hit-tested by a pure `SymbolLayer` that `OutlineTool` composes (so undo, save and pointer routing stay in one place). A new Layers section, a list picker and a plant-list panel are thin UI over it.

**Tech Stack:** TypeScript, Vite (`import.meta.glob`), vitest, `sharp` (build script), Figma MCP (`download_assets`), Playwright checks.

**Spec:** `docs/superpowers/specs/2026-10-17-symbols-design.md`

- Sizes: a symbol's size comes from a named source URL with its range, or it is marked `approximate` (family typical). The user reviews the size table (Task 2) before Task 3 starts.

## Review Focus

- A plan with no scale yet: a placed symbol uses a default size in page points and still follows zoom and rotation. Tested in Task 6.
- Rotation keeps the footprint size and the hit area; a rotated object is selected by tapping inside its rotated rectangle. Tested in Task 6.
- While placing is armed, a tap always places (even on top of another symbol); while not armed, overlapping symbols select the topmost (last placed). Tested in Tasks 6 and 7.
- Loading a plan whose `symbols` has an unknown library id, bad numbers, or a hidden id that no longer exists: unknown id is an invalid plan; a stale hidden id is dropped. Tested in Task 5.
- Undo and redo of place, move, rotate and delete are one step each (a drag is one step); hiding is not undoable. Tested in Task 7 and the Playwright check.

### Task 6: SymbolLayer (state and geometry)

**Files:**

**Interfaces:**
- Consumes: `symbolById`, `PlacedSymbol`, `isSymbolHidden`.
- Produces: `symbolDiameterPx`-style helpers and the layer:
  - `symbolSizePx(size: { w: number; d: number }, ftPerPt: number | null, pxPerPt: number): { w: number; d: number }` (feet ÷ ftPerPt × pxPerPt; when `ftPerPt` is null/invalid use `UNSCALED_SYMBOL_PT = 24` page points per 10 ft of size: `ft × 2.4 × pxPerPt`; never below 6 px).

  - `normalizeDeg(d: number): number` into `[0, 360)`.

- [ ] **Step 1: Write failing tests:** `place` returns `y1` then `y2` and stores the point; `move` and `remove`; `setRotation(…, -90)` stores 270; `symbolSizePx({w: 20, d: 20}, 0.05, 2)` is 800 and the unscaled fallback is `20 × 2.4 × pxPerPt` and follows `pxPerPt`; `hitTest` hits a plant inside its circle and misses outside; an object 4 × 2 ft rotated 90° is hit along its rotated long axis and missed where the unrotated rectangle was; with two overlapping symbols the later one wins; a `shown` predicate returning false makes it un-hittable; `counts()` per symbol id; `groups()` follows library order.
