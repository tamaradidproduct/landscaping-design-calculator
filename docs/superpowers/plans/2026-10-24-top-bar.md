# Top bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put back, plan name and menu, the Edit | Preview switch, Undo/Redo and an Export placeholder in one narrow bar across the top of the editor.

**Architecture:** A new `top-bar.ts` renders the bar from a small state object and hosts the existing `PlanHead` menu logic; `main.ts` owns the Edit/Preview state (today `sheetOpen`) and the Preview effect on the canvas (plot plan hidden, drawing fitted). A pure `plan-bounds.ts` supplies the rectangle to fit.

**Tech Stack:** TypeScript, Vite, Vitest, HTML-string UI builders, Playwright check scripts (`plan-builder/scripts/`).

**Spec:** `docs/superpowers/specs/2026-10-24-top-bar-design.md`

All paths are relative to `plan-builder/` unless they start with `docs/`. Run commands there.

## Global Constraints

- Bar height 48 px; controls at least 44 px hit area; tokens only from `src/styles/tokens.css` (never hand-edited).
- Keep ids `undo`, `redo`, `zoom-in`, `zoom-out`, `fit`, and the shortcuts ⌘Z / ⇧⌘Z. Zoom and Fit stay bottom-right on the canvas.
- Export is a placeholder: a normal enabled button; tapping shows the toast "Export is coming soon".
- Preview is read-only: Undo, Redo and the drawing tools do nothing and look dimmed; switching back restores the plan, zoom and pan.
- No model, storage or save changes.
- Check commands: `npm run lint`, `npm run typecheck`, `npm test`; Riesberg checks need `../samples/riesberg-plot-plan.pdf` and the dev server on 5180.
- Do not push or enable auto-merge; commit with the trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

- A long plan name must not push Undo, Redo or Export out of the bar at 820 px — Task 2 check.
- Entering Preview with an unfinished drawing must cancel nothing silently: drawing tools are inactive and the draft is kept until Edit returns — Task 3 test.
- Plot plan hidden in Preview must not change the saved "plan shown" setting — Task 3 test.
- An empty drawing (no outlines yet) in Preview fits the page, not nothing — Task 3 test.
- Redo stays faint when nothing can be redone, and Undo and Redo act through the bar and ⌘Z / ⇧⌘Z identically — Task 2 check.

### Task 1: Bar markup and Preview bounds (pure)

**Files:**
- Create: `src/top-bar.ts`, `src/top-bar.test.ts`, `src/plan-bounds.ts`, `src/plan-bounds.test.ts`

**Interfaces:**
- Produces (`src/top-bar.ts`):
  - `type EditorView = 'edit' | 'preview'`
  - `interface TopBarState { name: string; view: EditorView; canUndo: boolean; canRedo: boolean }`
  - `topBarHtml(s: TopBarState): string` — a `div.top-bar-inner` with, in order: left `button#back-to-plans` (aria-label "Back to Plans"), `h1#plan-title` (the name, escaped), `button#plan-more` (aria-label "Plan actions"); a `div.segmented#view-switch` with `button[data-view=edit]` and `button[data-view=preview]` (`aria-pressed` set from `view`); right `button#undo` and `button#redo` (icon-only, `disabled` from `canUndo`/`canRedo`, titles "Undo (⌘Z)" and "Redo (⇧⌘Z)"), a separator, `button#export` labelled "Export".
  - `const EXPORT_NOTE = 'Export is coming soon'`
- Produces (`src/plan-bounds.ts`): `interface Rect { x: number; y: number; w: number; h: number }`; `planBounds(state: { outlines: Record<string, Outline>; symbols?: Record<string, PlacedSymbol>; lines?: Record<string, PlacedLine> }): Rect | null` — the bounding box in page points of every outline point, symbol position and line point; null when there is nothing drawn.
